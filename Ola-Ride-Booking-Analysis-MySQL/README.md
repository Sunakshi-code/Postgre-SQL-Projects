# 🚕 Ola Ride Booking & Analysis using MySQL

A SQL project focused on analyzing Ola ride booking data using MySQL. This project explores ride bookings, vehicle types, cancellations, customer and driver ratings, payment methods, and booking revenue through SQL queries.

## 🎯 Project Objectives

- Analyze successful and cancelled rides.
- Identify the top 5 customers based on ride bookings.
- Calculate average ride distance for each vehicle type.
- Analyze driver and customer ratings.
- Evaluate successful booking revenue.
- Identify incomplete rides and their reasons.
- Explore payment methods and cancellation patterns.

## 🛠️ Key Concepts

- Aggregate Functions (`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`)
- `GROUP BY` and `ORDER BY`
- Filtering Data using `WHERE`
- Sorting and Limiting Results (`LIMIT`)
- Creating Views (`CREATE VIEW`)
- Ride Cancellation Analysis
- Customer and Driver Rating Analysis
- Revenue Analysis
- Vehicle Type Analysis
- Payment Method Analysis
- Handling Incomplete Rides
- Data Aggregation and Business Insights

## 📊 SQL Analysis

1. Retrieve successful bookings
2. Calculate average ride distance by vehicle type
3. Count customer-cancelled rides
4. Identify the top 5 customers by number of rides
5. Analyze driver cancellations due to personal and car-related issues
6. Find maximum and minimum driver ratings for Prime Sedan
7. Retrieve rides paid for using UPI
8. Calculate average customer ratings by vehicle type
9. Calculate the total booking value of successful rides
10. Retrieve incomplete rides with their reasons

## 💻 Tools & Technologies

- **Database:** MySQL
- **Language:** SQL
- **Dataset:** Ola Ride Booking Data

## 📌 Project Outcome

This project demonstrates practical SQL skills for analyzing ride-booking data and extracting business insights related to customer behavior, ride performance, cancellations, ratings, and revenue.
